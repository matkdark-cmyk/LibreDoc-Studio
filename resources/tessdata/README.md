# Modelos OCR offline (`tessdata`)

Coloca aquí los modelos entrenados de Tesseract para reconocimiento 100% local sin conexión:

- `spa.traineddata`
- `eng.traineddata`

Para descargarlos automáticamente en desarrollo ejecuta:

```bash
npm run setup:tessdata
```

Fuente oficial recomendada (`tessdata_fast`):
https://github.com/tesseract-ocr/tessdata_fast
